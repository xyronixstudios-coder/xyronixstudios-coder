## 🐆 Jubatus OS 2.0 — The Flagship

> A highly stable and modern **64-bit** operating system. Optimized from scratch to bring everyday desktop use together with top-level performance.

| Feature | Detail |
|---|---|
| **Desktop** | GNOME — customized theme components, smooth window transitions |
| **Package Manager** | `jps-64` — fully integrated with the 64-bit architecture |
| **Repositories** | Special repos for `student-projects` and studio software |
| **Hardware** | Broad driver support, modern CPU/GPU compatibility |
| **Security** | Optimized background services, minimal resource usage |

**What can you do with jps-64?**
- Fast install / update / remove via CLI or custom GUI
- Secure dependency management with Git-integrated scripts
- Easy access to special repositories like `student-projects`

## 🪶 Jubatus Lite 1.0 — The Lightweight Edition

> Specially optimized to bring low-spec, older-generation, or resource-constrained computers back to life. No unnecessary background load at all.

| Feature | Detail |
|---|---|
| **Desktop** | XFCE — minimum memory, maximum speed |
| **Package Manager** | `jps-32` and `jps-64` — slimmed down for the hardware |
| **Resource Usage** | Very low RAM / CPU consumption |
| **Boot** | Desktop in seconds thanks to a trimmed service list |
| **Target** | Educational labs and diverse hardware |
